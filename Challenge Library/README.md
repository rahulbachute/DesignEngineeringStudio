# Challenge Library

This folder stores DES Engineering Challenges organized by course and unit.

Recommended organization:

- Course code folder
- Unit folder
- Challenge folder
- Challenge authoring documents and compatible content files

Each released challenge should include:

- Complete metadata
- Project charter
- Engineering background
- Engineering activities
- Student-facing guide
- Faculty notes
- Assessment rubric
- Report or notebook expectations
- Review and version history

Do not change the frozen DES software platform while adding challenges.
