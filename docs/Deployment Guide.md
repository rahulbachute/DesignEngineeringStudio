# Deployment Guide

## Overview

Design Engineering Studio (DES / MEILP) is a static front-end project intended for deployment as a GitHub Pages site or similar static host.

## Front-End Deployment

1. Ensure all files are committed to the repository.
2. Publish the repository root or the outputs/meilp folder to GitHub Pages.
3. Confirm that the HTML pages load correctly in the deployed environment.

## Google Apps Script Deployment

1. Deploy the Apps Script project as a Web App.
2. Update the Apps Script URL in the shared configuration.
3. Verify that the live mode endpoints respond correctly.

## Post-Deployment Checks

- Open the faculty pages and confirm they render without errors.
- Test the dashboard, submissions, evaluation, outcomes, analytics, and reports flows.
- Confirm that the student workspace remains functional.
