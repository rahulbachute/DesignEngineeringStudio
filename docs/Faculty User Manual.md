# Faculty User Manual

## Overview

The faculty workspace allows faculty members to review submissions, conduct evaluations, track outcomes, view analytics, and generate reports.

## Core Workflows

- Open the dashboard to review key counts.
- Use submission management to filter and inspect submissions.
- Open the evaluation workspace to record marks and comments.
- Review outcome attainment and analytics dashboards.
- Generate accreditation-ready reports from the reports center.

## Tips

- Keep the application in development or mock mode while validating local workflows.
- Switch to live mode only after the Apps Script endpoint has been tested.
- Use the shared service layer for all data interactions.
