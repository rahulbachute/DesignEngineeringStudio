# Student User Manual

## Overview

The student workspace supports registration, challenge loading, submission, multiple attempts, and review of submission progress.

## Core Workflows

- Register or access the student workspace.
- Load the assigned challenge.
- Submit responses for evaluation.
- Review submission status after each attempt.

## Notes

- The student experience is intentionally preserved and remains compatible with the faculty workspace.
- Live integration depends on the configured Apps Script endpoint and sheet permissions.
