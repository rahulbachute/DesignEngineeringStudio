# Student Resources

This folder is reserved for student-facing DES support material such as notebook guidance, reporting expectations, reflection prompts, and general engineering learning resources.

Student resources should:

- Use clear and direct language.
- Support engineering reasoning without giving away complete solutions.
- Reinforce units, assumptions, diagrams, evidence, and reflection.
- Be consistent with the approved challenge rubric.

Do not place platform code, schema changes, or software modifications here.
