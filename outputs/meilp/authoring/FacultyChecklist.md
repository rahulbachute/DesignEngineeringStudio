# Faculty Checklist

Before publishing a challenge, confirm:

- Required files are present.
- JSON files parse successfully.
- `workflow.json` activity IDs are unique.
- Every workflow step has matching content.
- Rubric entries match assessed activities.
- Course mapping is complete.
- Individual or group attempt mode is configured correctly.
- Image and document paths are valid.
- Engineering brief reads like a real project.
- Instructor guide includes expected answers and common mistakes.
- Student guide explains what learners should do.
- Challenge launches through `assignment-workbench.html?assignment=<slug>`.
