# Faculty Authoring Example

## Scenario

A faculty member wants to create a challenge on shaft key design.

## Steps

1. Copy `authoring/challenge-template`.
2. Rename the copied folder to `shaft-key-design`.
3. Edit `config.json`:
   - Set `id` to `EC-03`.
   - Set course and outcome mappings.
   - Set `cceMarks`.
4. Edit `workflow.json`:
   - Add Project Charter.
   - Add Image Viewer or Image Label if diagrams are available.
   - Add Calculation activity.
   - Add Reflection and Submission.
5. Edit `content.json`:
   - Add prompts, resources, reflection questions, and takeaways.
6. Edit `rubric.json`:
   - Match every assessed activity.
   - Confirm marks total.
7. Add diagrams to `assignments/shaft-key-design/images/`.
8. Complete `ChallengeChecklist.md`.

## Rule

Do not write JavaScript or HTML. If a required activity type is unsupported, document it as a future component request.
