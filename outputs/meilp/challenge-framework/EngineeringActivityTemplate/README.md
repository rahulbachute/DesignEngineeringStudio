```json
{
  "id": "activity-id",
  "activityNumber": 1,
  "title": "Activity Title",
  "purpose": "What this activity develops.",
  "whyAmIDoingThis": "Short student-facing reason.",
  "engineeringTip": "Helpful engineering thinking hint.",
  "commonMistakes": ["Mistake 1", "Mistake 2"],
  "thinkLikeEngineer": "Prompt that encourages professional judgment.",
  "activityInstructions": ["Step 1", "Step 2"],
  "resourcesRequired": ["resource-id"],
  "expectedTime": "10 minutes",
  "marks": 2,
  "bloomLevel": "L3 Apply",
  "co": "CO1",
  "po": ["PO1", "PO2"],
  "pso": ["PSO1"],
  "componentUsed": "image-label",
  "facultyDiscussionNotes": "Questions or points for classroom discussion."
}
```

## 5E Alignment

Map each activity to one learning-cycle stage:

- Engage
- Explore
- Explain
- Elaborate
- Evaluate
