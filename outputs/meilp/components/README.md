# Components

Reusable UI components live here. Each component should be independent, documented, and driven by configuration or state passed into it.

Planned component families:

- Student Card
- Progress Bar
- Navigation
- Image Label
- Text Area
- Dropdown
- Submit

Sprint 1 provides `BaseComponent` and `ComponentRegistry`. Sprint 2 should add one component at a time with its own HTML contract, CSS hooks, JavaScript class, registration call, and validation notes.

Sprint 2A components:

- `student-info`
- `progress-bar`
- `assignment-navigation`

Sprint 2B components:

- `image-viewer`
- `image-label`

Run `components/demo.html` to see them working together.
