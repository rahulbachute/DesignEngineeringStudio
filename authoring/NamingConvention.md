# Naming Convention

## Folder Slugs

Use lowercase words separated by hyphens:

```text
assignments/shaft-design/
assignments/bearing-selection/
```

## Challenge IDs

Use the Engineering Challenge sequence:

```text
EC-01
EC-02
EC-03
```

## Activity IDs

Use stable lowercase IDs:

```text
project-charter
image-label
material-selection
engineering-calculations
reflection
submit
```

## Asset Names

Use descriptive lowercase names:

```text
side-stand-diagram.svg
assembly-view.png
load-path-reference.pdf
```
