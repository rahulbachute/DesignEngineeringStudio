# Authoring Best Practices

- Keep activity IDs short, lowercase, and stable.
- Use one activity per major learning action.
- Put all visible content in `content.json` or Markdown files.
- Keep media paths relative to the site root, such as `assignments/slug/images/file.svg`.
- Give every assessed activity a rubric criterion.
- Write prompts as professional engineering tasks, not exam questions.
- Use hints and notes to guide reasoning without giving away the answer.
- Keep reflection questions open-ended and specific to engineering judgment.
- Test the challenge with both individual and group attempt modes when enabled.
