    Platform Architecture

    Built as a reusable classroom foundation

    MEILP separates platform shell, shared components, data, assignment configuration, validation, and storage so future assignments can be added without redesigning the core.

    Configuration First

    Assignment metadata and cards are loaded from data files, with a migration path to assignment-level JSON configuration.

    Component Ready

    Components are isolated by contract so future reusable tools and dashboards can be added cleanly.

    Storage Adapter

    Local storage powers Sprint 0 while keeping Google Sheets, Forms, auth, and progress tracking behind future adapters.
