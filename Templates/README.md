# DES Templates

This folder contains reusable Markdown templates for creating DES Engineering Challenges. Faculty may copy these templates into a challenge working folder and complete them during authoring.

Recommended use:

1. Start with the metadata block in the standard template.
2. Complete the project charter.
3. Draft engineering background and activities.
4. Add tips, common mistakes, engineering judgement prompts, and reflection.
5. Prepare faculty notes, assessment rubric, and report or notebook expectations.
6. Review against the quality checklist before release.
