# Student Guide Template

Use this structure for `student-guide.md`.

## Your Role

Describe the professional role students are assuming.

## Project Context

Briefly explain the client, system, and engineering problem.

## What You Need To Do

List student tasks in sequence.

## Engineering Notebook

Students should record:

- Observations
- Calculations
- Assumptions
- Engineering Notes
- Conclusion

## Submission

Explain what students should review before submitting.
