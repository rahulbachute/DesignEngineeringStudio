# Reflection Template

Default reflection questions:

```json
{
  "title": "Reflection",
  "questions": [
    "What did you learn?",
    "Which engineering concept became clearer?",
    "Which Course Outcome do you think you achieved?",
    "What engineering skill improved?",
    "How would you improve this design?"
  ]
}
```

## Reflection Design

Good reflection prompts should:

- Connect learning to the Course Outcome.
- Ask students to name an engineering concept.
- Encourage professional improvement.
- Support qualitative evidence for OBE review.
