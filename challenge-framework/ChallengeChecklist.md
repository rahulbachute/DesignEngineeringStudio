# Challenge Quality Checklist

Use this checklist before publishing any Engineering Challenge.

## Project Charter

- [ ] Project Code present
- [ ] Project Title present
- [ ] Client or scenario owner defined
- [ ] Engineering background clear
- [ ] Problem statement realistic
- [ ] Learning context connected to course
- [ ] Objectives measurable
- [ ] Expected deliverables listed
- [ ] Professional responsibility stated
- [ ] Safety considerations included
- [ ] Acceptance criteria defined

## Learning Outcomes

- [ ] Course Outcome mapped
- [ ] Program Outcomes mapped
- [ ] Program Specific Outcomes mapped
- [ ] Bloom levels listed
- [ ] CCE marks total correct
- [ ] Difficulty level defined
- [ ] Expected time defined
- [ ] Prerequisites listed

## Engineering Context

- [ ] Resources are relevant
- [ ] Resources are optional unless activity requires them
- [ ] Image/document paths valid
- [ ] Engineering story is authentic

## Activity Quality

- [ ] Each activity has activity number
- [ ] Each activity has purpose
- [ ] "Why am I doing this?" included
- [ ] Engineering tip included
- [ ] Common mistakes listed
- [ ] Think Like an Engineer prompt included
- [ ] Instructions clear
- [ ] Resources required listed
- [ ] Marks, Bloom, CO, PO, PSO, and time included
- [ ] Component used identified
- [ ] Faculty discussion notes included

## Assessment

- [ ] Rubric criteria match workflow
- [ ] Marks total matches CCE marks
- [ ] Faculty remarks field available
- [ ] Common errors documented
- [ ] Outcome attainment fields present

## Reflection

- [ ] Reflection questions configured
- [ ] Course Outcome reflection included
- [ ] Engineering skill reflection included

## OBE Mapping

- [ ] CO mapping present for every assessed activity
- [ ] PO mapping present for every assessed activity
- [ ] PSO mapping present for every assessed activity
- [ ] Bloom level progression reasonable

## Technical Validation

- [ ] Required files present
- [ ] JSON parses successfully
- [ ] Workflow IDs unique
- [ ] Workflow IDs match content
- [ ] Rubric IDs match workflow
- [ ] Resource paths valid
- [ ] Mobile compatibility checked
- [ ] Accessibility labels and contrast reviewed

## Final Review

- [ ] Challenge launches in DES Workbench
- [ ] Student guide complete
- [ ] Faculty guide complete
- [ ] Engineering notebook section complete
- [ ] Submission summary fields complete
