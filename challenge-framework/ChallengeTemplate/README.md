# Challenge Template

Use this template to create a full Engineering Challenge.

## Required Files

```text
assignments/<slug>/
  config.json
  workflow.json
  content.json
  rubric.json
  engineering-charter.md
  challenge-overview.md
  faculty-guide.md
  student-guide.md
  evaluation-template.json
  images/
```

## Required Sections

- Project Charter
- Learning Outcomes
- Engineering Resources
- Engineering Activities
- Report / Engineering Notebook
- Reflection
- Engineering Takeaways
- Submission
- Faculty Evaluation
- Challenge Quality Checklist

Start from `examples/challenge-config-example.json`, `examples/workflow-example.json`, and `examples/content-example.json`.
